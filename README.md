# btcd-landing

Landing page tĩnh — **btcd.dev — dev nhưng mà cute**.

Trang một file (`index.html`), tự chứa HTML/CSS/JS, dùng Google Fonts và một quiz tương tác (chế độ HR & GF).

## Deploy

Site tĩnh, deploy lên Vercel với `index.html` ở thư mục gốc — không cần build step.

```bash
npx vercel --prod
```
